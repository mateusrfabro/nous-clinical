Onde hospedar o Nous Clinical

As opções de servidor, banco e storage — quanto custa cada caminho, qual recomendamos para lançar, e por que não ficamos presos a nenhum fornecedor.

🐳 Roda em Docker 🐘 Banco PostgreSQL 📦 Storage S3-compatível 🌐 Domínio nousclinical.com (nosso)

O princípio que destrava a decisão: o sistema é portátil

A escolha de hoje não é definitiva. Começamos no caminho mais fácil e migramos pro mais barato quando crescer — sem reescrever nada.

  • A aplicação roda em qualquer servidor ou PaaS que aceite Docker.
  • O banco se move com pg_dump/restore — muda 1 variável (DATABASE_URL).
  • Os arquivos (logo/exames) trocam entre R2/S3/B2 sem mexer no código.
  • O domínio só reaponta (DNS) — já é nosso.
➡️ Trocar de fornecedor é cópia de dados + reapontar o domínio — não recomeçar o projeto.
